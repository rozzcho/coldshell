# coldshell 설계 메모

Proof of Grind에서 넘어오면서 정한 것들. 채팅에서 합의한 내용을 그대로 옮겨둔다.

## 무엇이 달라졌나

| | proof-of-grind | coldshell |
|---|---|---|
| 증명 | 디스코드 음성방 카메라 3시간 | 매일 1분 이상 영상 + 그날의 코드 |
| 검증 주체 | 봇이 측정 + 참가자 배심원 | 서버의 음성 인식 |
| 보상 | 승자가 판돈을 나눠 가짐 | 완주자 전원 100% 환급 |
| 로그인 | 지갑 + 디스코드 | 지갑만 |
| 결과물 | 상금 | 상금 아님 — 이어붙인 영상 한 편 |

## 오늘의 코드

```
seed  = sha256(challenge_pda ‖ day_index ‖ blockhash(그날 00:00 UTC 직후 첫 슬롯))
word1 = WORDLIST[u16(seed[0..2]) % len]
word2 = WORDLIST[u16(seed[2..4]) % len]
```

- 워드리스트는 **BIP-39 영어에서 512개쯤 추려서** 쓴다. 전체 2048개에는 비원어민이 발음하기
  어려운 단어가 섞여 있다. 512² = 26만 조합이면 충분하다.
- 00:00 UTC 공개, 그날 23:59까지 업로드. 공개 시각을 랜덤하게 하지 않는다 — 시간대에 따라
  불공평해진다. 핵심은 "몇 시"가 아니라 "그날 안"이다.
- 코드가 그날에만 존재하므로 **미리 몰아 찍기가 원천적으로 막힌다.** 이것이 이 설계의 심장.

## 참가자 규칙

> 영상은 1분 이상, 10분 이하. **오늘의 코드를 앞 15초 안에 소리 내어 말할 것.**

앞뒤 두 번 말하게 하면 이어붙이기 공격을 더 막을 수 있지만, 끝에 말하는 걸 까먹어서 1분을
다시 찍게 되는 비용이 더 크다고 판단해 **한 번**으로 정했다.

## 검사 파이프라인

```
1. 길이 60초 이상            → 실패 시 즉시 반려
2. 오디오 추출 → 전사(Whisper)
3. 앞 15초에서 두 단어 찾기
   - 소문자 정규화 → 완전일치 → 편집거리 ≤1 → 음성학(Metaphone)
4. 같은 날 업로드끼리 파일 해시 비교 (남의 영상 그대로 올리는 것 차단)
5. 통과 → 온체인 기록
```

- **재시도는 그날 안에서 무제한, 결과는 즉시 응답.** 음성 인식이 못 알아들어서 스테이크를
  잃으면 그 사람은 다시 오지 않는다.
- **목표: 오탐 0, 미탐 10% 이하.** 미탐은 재시도로 구제되지만 오탐은 제품을 망친다.
- **Whisper에 코드를 프롬프트로 주지 말 것.** 프롬프트에 있는 단어를 없는데도 지어내는
  known issue가 있다. 조용한 영상이 통과해버린다. 편견 없이 전사하고 매칭에서 유연하게.
- 날짜 간 중복 검사(pHash 등)는 하지 않는다. 코드가 매일 바뀌므로 예전 영상 재사용은
  그 자체로 막힌다.

## 경제 구조

- 완주 → **스테이크 100% 환급.** 수수료 없음.
- **네트워크 수수료는 플랫폼이 부담.** 참가자는 SOL이 필요 없다. fee payer를 플랫폼 지갑으로.
- 포기분은 영상 보관·편집 비용으로 쓴다. 룰에 그대로 명시한다.
- **상금 분배·이월·multiply 비중 계산은 전부 없다.** 남의 실패로 만들어지는 상금이 없으므로
  도박 요건이 성립하지 않고, 통과율이 높아도 아무 문제가 없다.
- 보너스(3% 등)는 넣지 않기로 했다. 한 달을 해낸 사람에게 $0.60을 주면 경험이 싸구려가 된다.

### 참가비

- weekly: $10 단위로 $50까지 (월요일 시작)
- monthly: $20 단위로 $100까지 (1일 시작)

얼마나 아플지를 본인이 고른다.

## 프로그램

- `challenge`, `participant(stake)`, `record_day(day, video_hash)`, `claim(전액 환급)`,
  `close_participant(rent 회수)`
- **수령할 때 참가자 계정을 닫아 rent를 회수한다.** 안 하면 계정이 영원히 쌓인다.
  1000명이면 2~4 SOL이 묶인다.
- **보안**: 서버가 fee payer이므로 **서버가 직접 조립한 트랜잭션에만 서명**해야 한다.
  사용자가 보낸 트랜잭션에 서명해주면 남의 수수료를 대신 내주는 무료 지갑이 된다.

## 소각

전달이 끝나면 우리 쪽에는 아무것도 남기지 않는다. "보지 않습니다"보다 "남아 있지
않습니다"가 지킬 수 있는 약속이고, 수천 명의 사적인 영상을 영구 보관하는 것 자체가
언젠가 반드시 사고가 나는 부채다.

```
챌린지 종료 → 이어붙이기 → 전달 → 유예 기간(2~4주) → 원본과 완성본 모두 삭제
```

- **전달이 확인되기 전에는 절대 태우지 않는다.** 메일이 반송됐는데 지워버리면 그 사람의
  한 달이 영영 사라진다. 유예 기간과 소각 날짜를 처음부터 명시하고, status 화면에
  `your shell burns in 6 days` 같은 줄로 한 번 더 알린다.
- 유예 기간은 분쟁 기간보다 길어야 한다. 지우고 나면 "검사가 잘못됐다"는 이의에
  확인할 근거가 없다.
- **전달에는 원본 클립과 이어붙인 영화를 함께 넣는다.** 그러면 본인은 원본 해시를
  체인과 대조할 수 있고, 사후 검증 능력이 **본인에게만** 남는다.
- 완성본도 같이 지운다. 원본만 지우고 완성본을 들고 있으면 내용은 그대로 가진 것이다.
- **스토리지 버저닝과 라이프사이클 백업은 꺼둔다.** 켜져 있으면 삭제가 삭제가 아니다.
  ffmpeg·whisper가 만든 임시 파일도 같이 정리한다.

체인에는 해시만 남는다 — 아무것도 남지 않은 것의 존재 증명.

## 이름

회차는 `shell #14`. 화면에는 `N inside` — 누군지는 모르지만 몇 명이 지금 나와 같이 안에
있는지는 안다. 익명 그룹의 느낌을 사람 목록이 아니라 숫자 하나로 낸다.

## 아직 안 정한 것

- 영상을 이어붙여 어떻게 전달할지 (메일? 다운로드 링크?)
- 커뮤니티 탭 — 참가자가 한 줄씩 남기는 창. 누가 쓸 수 있는지(참가자 한정이 유력),
  스태프 삭제 기능은 처음부터 필요.
- CLI. 우선순위 낮음 — 공부하는 학생은 터미널 앱을 깔지 않는다. 웹 터미널이 이미
  그 느낌을 설치 비용 0으로 준다.

## 먼저 확인할 것 (다른 걸 만들기 전에)

1. **음성 검증 스파이크.** 테스트 영상 6개(조용한 방 / 카페 소음 / 빠른 말 / 웅얼거림 /
   노트북 마이크 / 폰)로 매칭률을 실측한다. 여기서 막히면 나머지를 만들 이유가 없다.
   안 되면 순서대로 후퇴: 단어 3개 → 숫자 네 자리(0 제외) → 화면에 코드를 적어 보여주기(OCR).
2. **업로드 파이프라인.** 1분 720p 실제 용량, 브라우저 녹화 vs 파일 선택, R2 presigned URL
   직결(서버 경유는 터진다), 서버에서 ffmpeg로 길이 확인.
